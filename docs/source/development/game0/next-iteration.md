## 完整可玩版的完成口径

保留已有三个章节和全部既有结局，以原任务为单位接入当前战斗。MVP在本轮表示达到可玩的质量门槛，内容范围沿用完整游戏。

每场接入必须同时检查：原剧情入口和出战配置、当前武器/敌人/部位护甲机制、实际资源消耗、原专用胜败结算，以及战后剧情推进和退出继续。复用已有教程、统一操作UI、素材和训练成果；只有原任务必需但缺失的能力才补做。训练改动以解决实际战斗问题为依据，不能成为持续推迟三章整合的前置工作。

实施按原任务矩阵逐场复验三章接入及原结局，同时关闭已发现的Boss可完成性阻断；Boss专项未完成时继续其他接入核对，最后冻结同一版本完成连续试玩和打包。全部原结局仍属于交付范围；当前尚未定位的分支必须继续查找原设计与工程，并保留为未完成项。

本轮开发排期以原任务接入矩阵为主线。已经制作的战斗、剧情和素材直接复用；逐场发现入口、敌人配置、技能、结算或存档缺口时补齐。大英招专项与章节接入分别推进，不能因为一个Boss尚未验收而暂停其他已有内容的整合。

实际推进顺序为：核对三章原任务与结局选择点 → 逐场接入现有战斗及专用胜败结算 → 核对实际成本、奖励、存档和战后剧情 → 修复阻断游玩的动作、输入和性能问题 → 同版本完整试玩与分支验收。下文I01–I07保留为需求索引，训练实验只在接入暴露必要缺口时开展，不要求先重新完成一轮算法扩展才能推进章节。

## 训练体验如何验收

选取近距威胁、中距攻击和远距接近等明确情境，先观察角色执行基础策略和当前模型。记录玩家想教的行为、实际成功动作标签、候选决策以及实战结果；区分学习动作、基础规则和队伍指令。

在未参与示范的站位或敌方节奏下比较基础AI、旧采用模型与新候选，每组至少三局。玩家能够根据报告找出具体不足并补练，例如近距缺少后退示范。新模型应在预先选定的目标上表现出可复现的变化，安全性与速度的取舍要直接显示；不通过削弱基线、挑选有利种子或隐藏失败来证明提升，也不要求任何示范都胜过基础AI。

采用、放弃、回滚与角色切换不得丢失另一角色成果；非法动作不记样本，候选未采用不得悄悄影响实战。训练和实际出战均复用现有摇杆、技能按钮及实体场景入口。
