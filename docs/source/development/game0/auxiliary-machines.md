## 最终图稿对照与闭合姿态修订

用户指出旧版本部分组件拼接与遮挡错误，并明确装备机右侧和后侧挡板在设计图中处于展开状态、游戏常态应当关闭。本轮以原图中的最终整机为位置与遮挡参考，修订为护盾机17组件、装备机19组件、悬浮机12组件。此修订取代旧版本的拼装质量结论，旧截图仅作历史证据。

- 护盾机：改用原闭合整片外壳作为可开合盖体，删除重复盖片和重复圆灯，修正芯体、前关节与履带位置，补齐履带纹理、观察窗和侧关节；绿色前关节位于前履带上层。
- 装备机：补齐连接臂与前后脚掌，校准侧箱和箱盖，控制面板拆成机身后的侧壳与前侧显示面，保留原像素。后侧挡板与右侧箱盖默认下滑关闭；采集/装备舱动作中才上滑展开，结束时回到闭合位置。滑动方式及开合行程是制作选择，关闭常态依据用户明确要求。
- 悬浮机：删除重复的白色推进器，恢复原黑色后侧结构，补齐前侧外壳与导管；前端长臂拆成后侧部分与前侧传感器，分别放在机身和外壳的正确层次。

新拆片使用原 PNG 的独立裁切和透明度遮罩，不重绘原图。脚掌与履带纹理按所属关节生成变换，保留统一绘制顺序，同时避免将脚掌裁在腿部遮罩里。迷彩由模型组件清单驱动，新增小件不会遗漏显形/隐藏；能量流与受击光点也随新拼接位置校准。

## 制作与动作

游戏 `Image/Auxiliary` 保留原图字节与 SHA-256，新增三套 Dora `.clip/.model` 和 `manifest.json`。`Tools/build_auxiliary_models.py` 可重建关节、裁切和时间轴；只读取透明度分析独立零件，输出原生模板遮罩几何，避免矩形裁切夹带邻近零件。没有重绘或修改原作者 PNG。遮罩随真实关节变换，保持原分件前后层次。

| 动作 | 原时间轴秒数 | 用途 |
| --- | --- | --- |
| deploy | 0.8 | 部署或重新补能后的启动 |
| idle | 2.0 | 传感器轻转、悬浮呼吸循环 |
| move | 1.2 | 四足交替、履带起伏、悬浮倾摆 |
| collect | 1.6 | 开启舱盖、真实拾取后的金色能量流 |
| shield | 1.0 | 启动维生防护表现 |
| hit | 0.5 | 真实机体受损后的震动与火花 |
| carry | 1.4 | 点击机体查看装备舱的开合表现 |
| depleted | 0.9 | 断能显形、沉降后保持终姿 |
| lose | 1.2 | 摧毁后停止动作，保持终姿 |

全部动作使用 `recovery=0.2`。一次性动作由实际 `AnimationEnd` 推进，不用固定短定时器切断。模型有 `energy-transfer` 和 `shield-ready` 时间轴事件；事件只驱动表现，金粉收益仍由原采集规则提交一次。表中时长不含 0.2 秒过渡。
