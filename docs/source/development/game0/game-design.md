## 1. 玩家目标与作品范围

玩家扮演进入游戏世界的代理导师，保护并培养学员，用亲自示范积累战斗经验，再带领小队执行任务，逐步理解人物与接触事件。作品必须让玩家能回答“我教了什么、她学会了什么、这如何帮我完成任务”。

| 层级 | 内容 | 完成标准 |
| --- | --- | --- |
| 核心切片 | 现有开场/教程、必要基地入口、1 名可训练学员、1 个训练对手、1 个实战任务、结算/重试/存档继续 | 从新建游戏走通，训练模型实际参与实战；放弃训练不覆盖旧成果；退出后能继续 |
| 首章可玩 | 第一章关键剧情、少量任务、通讯、成长反馈、学员与战术指令逐步解锁 | 第一章有明确目标、转折、章末结果；训练和队伍选择至少各影响一次结果 |
| Game 0 完整首版 | 三章连贯剧情、训练及养成、小队任务、最终任务和结局、署名及可分发包 | 新建到三章终点可走通；不是只用“待续”代替缺失结局 |

首个切片建议使用导师和妮妮莉特；先核验其可用战斗动作。完整首版的小队上限提案为导师加最多 3 名学员；历史流程图最多 5 人的布局保留为可扩展 UI，不先强制填满。首版优先本地单人、离线训练；联网账号、角色借调、在线 AI 分享、DAO/NFT 等不进入这次游戏完成任务的依赖链。

动作优先复用现有枪械/闪避教程；剑盾大锤弓箭、四色克制、方案 5 等作为历史候选，不要求同时实现。是否换用新战斗方案需实机比较，见决策记录。

## 2. 核心循环

收到剧情/通讯任务 → 查看任务敌人与目标 → 选择学员和技能 → 亲自示范 → 生成候选模型 → 观看试战并比较 → 采用或放弃 → 编队执行任务 → 获得剧情/能力反馈 → 回基地再训练。

在各环节都显示下一步和返回路径。没有采用过模型的学员不能被界面暗示为“训练完成”；初学者可用明确标注的基础 AI 进入试战，但必须说明该行为不是从玩家示范学来的。

## 3. 训练机制

### 训练准备与示范

- 选择学员、技能组、已解锁的对手；显示这次要学习的动作与对手意图。
- 示范时玩家直接控制被训练学员，不用导师的动作数据假冒学员技能数据。
- 初始建议单轮 60–90 秒，可提前结束或重置；时长是可调预算，待试玩确认。
- 第一轮聚焦 2–3 个可学动作，例如攻击、闪避、停手等待。转向、基础追敌、落地、非法动作处理保留为显式底层规则，不与学习准确率混在一起。
- 首轮不额外引入复杂体力系统；如复用动作确有体力约束，训练特征必须同步包含可用性条件。

### 采集、建模与试战

采集实际成功的动作及当时的状态，不采被冷却、硬直或条件拒绝的按键。等待需要显式的“等待”标记或稳定窗口，避免长时间 idle 淹没有效样本。这个处理是对 S05 旧采集规则的新增提案。

首个原型选择小型分类决策树，先用朝向、距离区间、敌方威胁动作、自身动作可用性等少量特征。引擎建树返回的准确率只代表接口所定义的训练数据指标，不作为战斗胜率或泛化能力宣传。

试战使用训练未见过的固定种子/站位，建议 3 局起步。报告样本量、动作分布、非法动作被拦截次数、存活、耗时及胜负，显示“遇到远距离冲击会先闪避”等可读决策摘要。阈值先由切片比较基线建立，不能保证任意示范都改善胜率。

候选模型默认不生效。玩家点击采用后才替换当前采用版本；点击放弃、取消或建模失败均保留旧版本及其绑定编队。允许回滚到上一已采用版本。

### 学习失败也能继续

空样本、缺少动作、单一标签、未知动作、特征版本不兼容等给出可操作提示；不把模型失败作为角色永久损失。显示“缺少近距离示范”等问题，提供重练或基础 AI 试战入口。复训追加/替换由玩家明确选择，避免误删上一组数据。

## 4. 战斗与战术

导师可直接行动；学员执行所采用模型。首个实战任务仅验证单学员，后续才增加队伍协作。导师的伤害与任务规则要防止玩家完全绕开学员训练完成全部挑战。

| 指令提案 | 语义 | 与学习模型关系 |
| --- | --- | --- |
| 跟随 | 保持导师附近，遇敌按模型决策 | 只改变目标和活动范围 |
| 集火 | 优先攻击指定有效敌人 | 不替学员直接选择攻击/闪避动作 |
| 守位 | 在指定区域活动并处理接近敌人 | 区域是约束，不是硬改学习动作 |

指令有图标、目标反馈和解除方式。目标死亡/离场时取消引用并回到可见的默认状态；多个学员不能因重叠目标卡死。复杂共享视野、实时借调、持续增援和占领战暂排在核心切片之后。

动作要有可读前摇、命中、硬直及冷却反馈；首版不复用旧稿 1.5 倍敌人、60%/80% 防御等数值作为无条件规则。所有数值由角色动作与敌人配置统一驱动，进行种子固定的试玩调参。

## 5. 成长、道具与奖励

训练能力成长与剧情关系成长分开记录。能力由采用的模型与技能解锁决定；角色互动可解锁训练条件、能力或克服缺点，不能让随机失误掩盖训练效果。

2026-10-05 用户新增要求：每场任务引入武器与道具的资源投入和使用成本，以尽可能少的资源完成任务为目标，配置不当可导致任务净收益为负。剧情解锁仍为一次性事实，与可结算的物资收入分离；具体契约见[任务资源与装备选择](resource-economy.md)。装备图使用用户提供的原设计图，成功/失败分别复用已有专用结算界面。旧“暂不做资源经济”限制由本次要求替代；不据此引入随机词条或稀有度。

结算至少显示任务目标、结果、学员实际表现、奖励及下一步。重复结算不得重复发奖。

## 6. 挑战与失败

第一任务检查一个学过的行为；第二任务改变距离或敌方节奏，要求复训；第三任务加入两名学员与一次战术调遣，避免仅提高 HP 延长战斗。

任务配置明确胜利条件、失败条件和可选目标。初始提案：完成目标获胜；全队失去战斗能力或任务超时失败；用户退出视为中止而非失败。教程按事件教学，需要保底提示，不让漏掉一次按键导致永久等待。

失败可立即重试、返回训练或回基地；不会抹掉采用模型和已完成剧情。失败不能与奖励提交同时发生。剧情内“世界不能读档”是故事设定，产品依然支持退出后继续与失败重试，其叙事解释在剧情文档中统一。

## 7. 输入与体验

训练示范、导师动作和战术指令采用相同清晰的操作提示。当前 `Control`、HUD 与历史键位需要实际测试后确定，文档不提前断言所有设备可用。

当前教程枪械规则：轻点手枪按钮或 J 键向前水平射击；按住时瞄准线在上下方向扫动，释放时按当前角度开火。0.15 秒以内按压归为轻点，实际实现于 Tutorial/System；已验证 macOS 短按及真实投射物，触摸长按/手柄尚待对应设备验证。训练只记录成功执行的动作，不把瞄准过程的每一帧当成新攻击示范。

首个开发验收先在 macOS 键鼠上走通；发布候选再覆盖 Windows/Linux 及 Android/iOS 的所选范围。移动端按横屏设计检查触摸、字体、安全区和暂停恢复；手柄根据输入矩阵决定，不作为未经验证的承诺。

最终节奏以“训练变化能看懂、试战能比较、失败知道怎么改”为评价核心。章节时长与任务数量在核心切片实测后估算，当前不硬承诺总时长。

### 学院内训练入口与现有 UI

角色从备战室右门进入 B 区走廊，再由右门进入训练室；走近发光终端后进入虚拟训练场。训练场结束回训练室，继续学院漫游。该路径按 2026-10-03 用户确认优先于早期快捷入口提案。示范使用现有虚拟摇杆、枪械技能与等待技能，A/D/J/K 为对应键盘路径；样本、候选与采用管理不替换统一战斗输入。已存在的训练室和虚拟训练场资源应复用，确有缺失的素材再补充并记录来源。

### 保留示范与可读的训练对照

“近处/中距/远处对练”重置对练位置并保留已有样本，“重新示范”清空本轮样本。玩家用原摇杆和技能按钮重复示范不同意图，结束后查看学会的动作种类与示范准确率。基础 AI 对照可单独观看，不会产生或采用训练成果。候选对照显示三场胜利、平均生命与用时，提示玩家比较安全性和速度的取舍；不以胜利一次等同训练全面有效。

当前公开示范验证覆盖近距后退、中距射击、远距接近。它证明了三动作策略的保存与实际执行，不代表已经学会针对小饕餮全部五种攻击的战术，也不代表多学员训练已完成。

### 地面调查与辅助机工作稿

完成车厢交谈与第二封邮件后，从车厢右侧部署。妮妮莉特需编入且有已采用模型，导师与学员携采集辅助机进入遗弃城市。漫游先了解维生场，再收集沿路金粉、观察前沿强敌；集合使队伍靠拢并在辅助机旁恢复生命。当前初次地面强敌暂采用现有大饕餮资产，是原剧本未指名BOSS的运行选择，不用普通小饕餮加血替代陌生强敌。已接守住退路实战、乌云实体救援与休息室交谈。学员继续使用已采用模型，地面驱动能量100、每次真实射击消耗12；能量不足等条件触发援助，不人为删除训练成果或强制学员受伤。原策划三机型、两面作战和风火配合仍不能由本轮单机采集功能宣称完成。


## 分角色训练扩展

休息室完成合作与地面计划后，训练场可在妮妮莉特与乌云之间切换，两者各自保存采用成果和上一版本。未处理的示范或候选先采用/放弃，切换不默默丢样本。妮妮莉特既有射击/后退/接近策略保留；乌云支持刀击、射击、接近、后退、等待，真实示范可学近刀击/中射击/远接近。已采用模型可通过成果复战按钮再看三场基础对照。

独立角色训练不等于已完成同时部署或原稿风火联动。能源回收任务仍需两个已采用模型、共同辅助机、两侧目标、定位与回收的实际任务结果；乌云原刀击不能直接称为藏银寒风。


## 第二章能源回收的双学员闭环

完成地下城合作和地面计划后，分别采用妮妮莉特/乌云的成果，再从列车右侧部署。原编队卡片各自决定学员是否加入，缺任意一人或其成果不能开始。三人实际沿城市漫游，夜光镜标出中央能源箱。进入遭遇战后，两名学员在同一场景分别执行保存模型，导师以原摇杆和射击按钮处理中央怪物；集合仍是明确队伍指令，不冒充学习动作。

清理三怪后先记录道路安全；玩家还需亲自打开中央箱，在数据流演出和原Yarn交谈后保存能源回收。失败、辅助机损毁和撤离均无奖励。结果可在通讯第四页重读，重复通关/开箱不重复奖励，两份采用成果完整保留。

独立鸿鹄焰火/藏银寒风使用素材真实攻击事件、完整结束与0.2秒回prepare；导师朝向引导，石柱实际挡击，同向寒风增强物理火箭命中。首次胜利实际挡击与风火增强命中兼具时两份能源，否则一份；事务保存且重打不增发。原生风火路径、角度/冷却/旧奖励迁移及重启已验证，程序化石柱与效果仍待美术精修。
